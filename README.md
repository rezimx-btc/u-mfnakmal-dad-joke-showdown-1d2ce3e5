## The joke

> I told the ocean my best joke. It didn't laugh - it just waved.

## Why it's funny

The joke sets up a classic dad-joke scene — telling a joke to someone who can't respond — and lands on a clean pun: the ocean "waving" is both a greeting and what waves do. The straight-faced delivery makes the groan land harder, because the punchline pretends the ocean's natural behaviour is a polite reaction.

## How to run

```bash
python3 main.py
```

Prints exactly the joke as one line on stdout and exits 0.
